# Assessment requirement check

This maps the supplied technical assessment to the implemented code and saved evidence. **Live** means the saved local models and configured OpenAI API produced the result; **automated** means deterministic tests or Streamlit AppTest, often with mocks. The assessment's three published examples are visible acceptance fixtures, not unseen test data.

| Assessment item | Implementation and evidence | Verification / limit |
